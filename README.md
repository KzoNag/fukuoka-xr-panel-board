# パネルディスカッション進行ボード

福岡XR部ミートアップ 2026.09 のパネルディスカッション(15:10〜15:50)用。
参加者がスマホからトピックを投稿・投票し、進行役が好きなトピックを選んで
タイマー付きでプロジェクターに出す。オンライン参加者も同じURLで参加できる。

依存は Node 18+ のみ(ライブラリなし)。公開には `cloudflared` を使う。

## 起動(当日)

```bash
./start.sh
```

これで次が動く。

| 画面 | URL | 用途 |
|---|---|---|
| 参加者 | `https://xxxx.trycloudflare.com`(起動時に表示) | QRで配る。投稿・投票・いまの話題とタイマーが見える |
| 進行役ボード | `http://localhost:8787/board?key=…`(起動時に表示・自動で開く) | **これを画面共有で投影**。いまの話題+タイマー+QR、右に全トピック一覧。`key` 付きだと一覧の各行に「▶ 話す / ✓ 済 / ✎ / 削除」、タイマー操作、運営トピック追加、設定が出る |
| 表示だけ | `…/board`(key 無し) | 操作ボタンが出ない同じ画面。別モニタや配信用に |

参加者URLはサーバーに自動登録され、ボードのQRに反映される。
進行役ボードはスマホからも開ける(`https://xxxx.trycloudflare.com/board?key=…`)。
`/admin` は旧URLの互換で `/board` と同じ画面。

- **本番前は `./start.sh --fresh`**: `data/data.json` を消して初期状態(運営トピック6本・新しい進行役キー)から始める
- **ボードはブラウザをフルスクリーンにして投影**(Chrome: 表示 → フルスクリーン / `⌃⌘F`)。720pでタブバーが乗っても崩れないようにはしてあるが、フルスクリーンが確実
- 状態は `data/data.json` に残る。落ちても `./start.sh` で続きから。サーバーが落ちたら `start.sh` が自動で再起動する
- トンネルが落ちたら `start.sh` が張り直し、QRも自動で切り替わる。**ただしURLは変わる**ので、すでに開いている参加者には「QRをもう一度読んで」と一声かける(参加者画面にも同じ案内が出る)
- 会場ネットで cloudflared が使えないとき: `./start.sh --no-tunnel`(現地の同一Wi-Fi限定、オンラインは不可)。トンネル作成に失敗したときも自動でこのLAN URLにフォールバックし、10秒ごとに再試行する
- 荒らしが来たら: 進行役画面の「削除」で個別に消すか、「危険な操作 → トピックを全部消す」。投稿・投票は IP ごとに毎分200回で制限している(会場NATで全員同じIPになるので緩め)

## 進め方(想定)

1. **オープニング(14:00)** でボードの「募集中」画面を出してQRを告知。LT中に溜まる
2. **15:10** 右の一覧で「▶ 話す」→ 左が「いま話しているトピック」+7分タイマーに切り替わる
3. 票数順に並ぶが、**上位からでなくても自由に選んでよい**。全リストは常に右側に出ている
4. 残1分で色が変わり、0で「時間です」+チャイム(一度「チャイム: オフ」をクリックして有効化)
5. タイマー下の「✓ 済にする」で下に落ちて募集中画面に戻る → 次を「▶ 話す」。伸びそうなら「+1分」「+3分」
6. 終わらなかったトピックは交流会へ

## 構成

```
server.js        HTTP + ロングポーリング + JSON永続化(依存なし)
public/
  index.html     参加者(投稿・投票)
  board.html     ボード + 進行役操作(ダーク固定。?key= があると操作が出る、x-admin-key で認証)
  app.js/app.css 共通(state購読・並び順・トークン)
  vendor/qrcode.min.js  qrcode-generator 1.4.4 (MIT)
start.sh         サーバー + cloudflared quick tunnel + URL自動登録
data/            data.json / ログ(gitignore)
```

- 同期はロングポーリング(`GET /api/state?since=<version>` を変化まで最大25秒保留)。SSE は cloudflared でバッファされて届かなかった(docs/adr/0002)
- 投票は端末ごと(localStorage の匿名ID)に1トピック1票、タップで取り消し
- タイマーはサーバー時刻基準(`serverNow` で端末の時計ずれを補正)
